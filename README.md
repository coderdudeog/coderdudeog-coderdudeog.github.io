My project is a rocket flight controller board I designed in KiCad. It uses an STM32F103 MCU, a BMP280 barometer, and an ICM2060 ICM. It has a
microSD card slot to store data collected from the sensors. It runs on 3.3v gathered from a single cell LiPo battery. There's a power 
regulation system built into the DAC on PA0. That's about it.
